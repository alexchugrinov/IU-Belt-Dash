# IU Belt Dash

A Geometry Dash-inspired browser game built with HTML, CSS, and JavaScript.

## Getting started

Open `index.html` in a browser and select **PLAY NOW**.

- Press Space, Up, or W (or tap/click) to jump.
- Hold jump while flying to climb; release to descend.
- Reach each belt to unlock its runner skin. Pick a skin from the menu, or create one with your own colors and shape.
- Unlock the chameleon, lion, and leopard skins at belts 3, 5, and 7.
- Skin choices and unlocked belt skins are saved on this device.
- Press R to respawn at a checkpoint and P to pause.

## Files

- `index.html` — game page and canvas
- `style.css` — layout and visual styling
- `script.js` — game logic, skins, animation loop, and input handling
